# Likes & Dislikes Slides

Slides de aula: **love · like · enjoy · don't mind · hate + -ing**.

## Como editar (sem perder nada)

1. Abra o arquivo `index.html` aqui no GitHub e clique no lápis ✏️ (Edit).
2. Mexa só no bloco **CONTEÚDO EDITÁVEL** no topo do `<script>`:
   - `SUBJ` — sujeitos dos botões
   - `THIRD` — quais sujeitos são 3ª pessoa (loves / doesn't mind)
   - `VERBS` — verbos e suas formas
   - `ACTS` — atividades `["forma base", "forma -ing"]`
   - `CHAIN` — a sequência do Chain drill
3. Clique em **Commit changes**. Em ~30 segundos o site atualiza sozinho.

Toda mudança fica salva no histórico (aba **History** do arquivo). Se algo quebrar,
dá pra voltar a qualquer versão anterior — nada se perde.

Dica: mantenha as aspas `"` e as vírgulas `,` no lugar. Se a página ficar em branco,
provavelmente faltou uma delas.
